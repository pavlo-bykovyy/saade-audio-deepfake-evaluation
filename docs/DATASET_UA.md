# Дані

- Публічне посилання: [ATV-UA](https://huggingface.co/datasets/adam-i/ATV-UA).
- Робочий локальний набір на сервері: `AUA/01_audio`, метадані `metadata_audio.csv`, окремі джерела Common Voice, FLEURS, DRSSU, власні AUA-записи, New TTS.
- Підкорпус контролю: пари REAL–TTS з однаковим текстом, груповані за голосами та первинними записами.
- Дані й права доступу не входять до GitHub-архіву. Перевірте ліцензії джерел і право поширення згенерованих TTS.

**Увага:** назва публічного датасету не гарантує, що він повністю збігається з локальною робочою версією AUA, на якій отримані числові результати. Для відтворення потрібні версія датасету та контрольні суми.
