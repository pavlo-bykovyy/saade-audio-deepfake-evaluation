# Хронологія коду

| Версія | Зміст | Статус |
|---|---|---|
| v1–v3.1 | Каталогізація, адаптери метаданих, ранні сценарії, DRSSU | Історичні |
| v4–v5.1 | Розробка сценарного навчання та пілотна оцінка E1/E2/E3 | Інша постановка; не фінальна для статті |
| v6–v6.2 | Реальні REAL–TTS пари та виправлення Piper/JSON | Актуальна остання v6.2 |
| v7–v8 | Перехід до сценарного **тестування готових** моделей | Замінено v9 |
| v9 | Повне AUA + matched; 21 сценарій; 3 моделі | Baseline із zero-padding |
| v9.1 | Repeat-padding, корекція метрик AASIST/AASIST-L | Актуальна основна evaluation |
| v9.2 | Фіксація результатів та одноразовий hidden test | Остаточний протокол |

Оригінальні вихідні файли ранніх релізів зібрано з відповідних архівів. `MANIFEST_SHA256.json` усередині історичних пакетів стосується файлів цих пакетів, а не всього GitHub-репозиторію. Модифіковано лише небезпечну конфігурацію історичного `v9_2_ready_safe_template` (фаза тестування вимкнена за замовчуванням). Перевіряйте `CODE_MANIFEST_SHA256.json` у корені для цілісності поточного пакета.
