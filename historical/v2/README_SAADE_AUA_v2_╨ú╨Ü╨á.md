# SAADE–AUA 2026 v2 — Jupyter-проєкт

Версія: 2.0, 14.11.2026. Програмний проєкт для обробки локального AUA на JupyterLab-сервері.

## Вміст

- `SAADE_AUA_Full_Pipeline_v2.ipynb` — повний експеримент: каталог, збирання порівнюваних даних, 800–1500 сегментів (за можливості), train/validation/hidden, E1/E2/E3, 21 сценарій, аудіоплеєри, таблиці й графіки, 3–5 seeds, статистика, one-shot hidden test.
- `SAADE_AUA_Results_Viewer_v2.ipynb` — повторне відкриття попередніх результатів **без нового навчання**. Дає прослухати всі варіанти конкретного аудіо, показує таблиці по кожному сценарію і графіки.
- `saade_core.py` — генератор, моделі, навчання, сценарні прогнози, показники.
- `saade_visuals.py` — аудіо й ілюстрації: 21 WAV-плеєр у Jupyter, 21 осцилограма і спектрограма для прикладу, 21 confusion matrix, криві BA/EER і теплокарти для всіх моделей та режимів.
- `saade_v2_methods.py` — діагностика source-confounding, групування за мовцями, неперекривні сегменти, повтори seeds, GEE interaction та захищений одноразовий hidden test.
- `requirements_SAADE_v2.txt` — рекомендовані додаткові бібліотеки.

## Запуск

1. У JupyterLab створіть папку `SAADE_AUA_v2`, завантажте туди **всі** файли ZIP, розпакуйте.
2. Переконайтеся, що у тій самій папці поруч із `.ipynb` лежать усі три Python-модулі.
3. Відкрийте `SAADE_AUA_Full_Pipeline_v2.ipynb`.
4. У комірці `Етап 0` перевірте `DATA_ROOT = Path('/home/jovyan/work/AUA')`.
5. Якщо немає `soundfile`, `statsmodels`, `ipywidgets`, виконайте `%pip install soundfile statsmodels ipywidgets`, після чого `Kernel → Restart Kernel`.
6. Запустіть `Kernel → Restart Kernel and Run All Cells`. Початково `RUN_SEED_REPEATS=False` і `RUN_FINAL_HIDDEN_TEST=False` — це **навмисно**: спершу потрібна перевірка на validation, не можна відкривати hidden під час налаштування.
7. Після перевірки результатів, без зміни split/сценаріїв, перемкніть `RUN_SEED_REPEATS=True` та виконайте комірку `Етап 10` для 3–5 повторів. Для першого запуску радимо GPU і зменшені `MAX_BASE_FILES`/`TARGET_SEGMENTS` (тільки з **новим EXP_NAME**).
8. **Тільки після фіксації** протоколу, усіх повторів і виправлення джерел real/fake виконуйте `RUN_FINAL_HIDDEN_TEST=True`. Фінальний тест створює `HIDDEN_TEST_ONE_SHOT_STARTED.json` і навмисно відмовляється від повторного запуску.
9. Звіти та рисунки будуть у `/home/jovyan/work/results/SAADE_AUA_2026_v2_5level/`. Аудіо **не копіюється** в архів. Для звуку відкрийте ноутбук і скористайтеся плеєрами.

## Умови науково коректного експерименту

| Пункт | Що робить v2 | Обмеження |
|---|---|---|
| 1. Зіставні real/fake | `source_balance_audit()` перевіряє, які джерела містять обидва класи; `PAIRING_POLICY='strict_source'` відсікає всі інші | Файли різних джерел не стають порівнюваними від нормалізації звуку. Строгий режим може зупинити експеримент, доки немає потрібних файлів. |
| 2. ID | Використовує `speaker_id`, `source_record_id`, `voice_id`, `generator`, SHA й позначає невизначені записи | Якщо метаданих фізично немає, ID неможливо достовірно відновити автоматично. Не позначайте таких мовців як незалежних. |
| 3. 800–1500 | Неперекривні 4-секундні фрагменти утворюються **після** поділу master за групами | Кількість фрагментів не дорівнює кількості незалежних мовців або генераторів. Якщо даних замало, звіт показує фактичний дефіцит. |
| 4. Seeds | Є комірка 3–5 повних повторень E1/E2/E3 | Для порівняння seed використовують незмінні split і `scenario_seed`; запускається свідомо через прапорець. |
| 5. Архітектури | Базові Spectrogram CNN / Raw Wave CNN / MFCC-SVM плюс фактичні AASIST, RawNet2, frozen WavLM encoder + trainable head | AASIST/RawNet2 вимагають локального клону офіційного репозитарію; WavLM — `transformers` та checkpoint. Без цих залежностей не заявляйте, що моделі були протестовані. |
| 6. Статистика | ASRI, BA, F1, EER, ROC-AUC, FAR, miss rate, cluster-bootstrap, GEE `model×regime`, порівняння по кожному сценарію | GEE при замалій кількості незалежних груп позначається CHECK. Validation не є незалежним доказом після оптимізації E3 на validation. |
| 7. Hidden test | Зафіксовані моделі/пороги, one-shot-маркер, всі 3–5 seeds тестуються ОКРЕМО | Не повертатися до налаштувань за результатами hidden. Не виконувати, поки confounding не закрито, для серйозної статті. |

## П'ятирівнева шкала

Оригінал + 4 категорії × 5 рівнів = **21 сценарій**:

- Гаусівський шум: SNR **20, 15, 10, 5, 0 дБ**.
- Справжнє MP3-кодування/декодування через `ffmpeg`: **64, 48, 32, 24, 16 kbps**.
- **Синтетична**, а не виміряна кімнатна реверберація: номінальний RT60 **0,2; 0,35; 0,5; 0,7; 0,9 с**.
- Butterworth low-pass: гранична частота **7000, 6000, 5000, 4200, 3400 Гц**.

Попередній `v1_3level` також підтримується **окремим запуском**. Не порівнюйте `L2` двох профілів як той самий вплив: їхні параметри відрізняються.

## Як працює аудіо

`V.show_audio_gallery()` створює і показує **всі 21** перетворення реального і синтетичного файлів, кожен у відтворюваному плеєрі. Осцилограми та спектрограми зберігаються в `visuals/validation/`; аудіоплеєри відтворюють локальні фрагменти без експорту у звіт. Сигнал нормалізується **лише в плеєрі**, а не перед оцінюванням детектора. За потреби `V.make_interactive_player()` дозволяє вибрати будь-який доступний аудіосегмент.

`V.report_scenario_tests()` друкує числовий звіт **для кожного 21 сценарію й кожної E1/E2/E3 × архітектури**, а також confusion matrix, ROC, теплокарти та криві за інтенсивністю.

## Моделі

Офіційні проєкти для встановлення: 

- AASIST: https://github.com/clovaai/aasist
- ASVspoof 5 RawNet2: https://github.com/asvspoof-challenge/asvspoof5
- WavLM: https://huggingface.co/microsoft/wavlm-base-plus

Параметри AASIST / RawNet2 можуть вимагати підлаштування під версію відповідного репозиторію. Вони **не** завантажуються автоматично в ноутбуці — це захищає серверні залежності та не створює хибної ілюзії виконання моделі.

## Експериментальні результати

Ми перевірили код **на невеликій синтетичній структурі AUA**, у тому числі 21 сценарій, реальні файли MP3-перетворень, інтерактивні/вбудовані аудіодані, таблиці E1/E2/E3, 3 seeds і окремий hidden за seed. **На реальному AUA код v2 ще не виконувався.** Жодні графіки з тестового середовища не слід переносити в наукові висновки.

## Попередні виправлення

- Усунуто подвоєння `own_master`/`own_processed` і фізичних копій у `05_splits`.
- Не змішуються `v1_3level` і `v2_5level`.
- Для сегментів збережено групу первинного файла та точний часовий зсув.
- Додано незалежний сценарний seed, однаковий у різних навчальних повторах.
- Локальний каталог і підсумкові звіти зберігаються тільки в новому `cfg.out`.
- Дані без підтвердженого speaker/source ID не визнаються незалежними автоматично.
- При недостатній кількості груп статистика повертає CHECK, а не PASS.
- Hidden test потребує одноразового маркера, а результати різних seeds не трактуються як незалежні приклади.
