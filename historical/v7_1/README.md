# SAADE–AUA v7.1 — сценарне оцінювання готових моделей

Це виправлення статистичного аналізу на основі наданого користувачем `SAADE_SCENARIO_EVALUATION_v7_SMOKE_12_FOR_REVIEW.zip`. Алгоритми інференсу, вибірки, набори акустичних сценаріїв, перетворення сигналів та пороги калібрування не змінені щодо v7.

## Що виправлено

1. Файл `06_RANK_REVERSALS.csv` розрізняє нічию на чистому аудіо, зміну парного порядку моделей і розв'язання нічиїх. Показник `rank_reversal` лишається невизначеним, якщо clean не має єдиного лідера.
2. В `07_CLUSTER_ROBUST_FACTORIAL.txt` виводиться `SKIPPED` замість непридатної статистики F за 12 незалежних пар і 16 параметрів факторної моделі. При достатній кількості пар регресія залишається доступною з обмеженням висновків до перевірених голосів.
3. `MCDM_consensus` не враховує двічі тотожні за обраною нормалізацією `DnM_benefit` та `WSM`. Обидва відображаються для аудиту, але тільки `WSM` входить у консенсус.
4. Новий `06_SCENARIO_AUC_ALERTS.csv` позначає сценарії з ROC-AUC ≤ 0.10 або ≥ 0.95. Клас, оцінки і модель **не перевертаються автоматично**.

## Результат контрольного тесту на завантаженому архіві

- Повний прогнозний файл: 1 512 прогнозів, 3 моделі, 12 REAL–TTS пар, 21 сценарій.
- ASRI-Audio: AASIST 0.60625; AASIST-L 0.56667; Wav2Vec2 0.56042.
- Wav2Vec2: ROC-AUC = 0 на 5/5 сценаріях шуму; потрібна незалежна перевірка передобробки та семантики класів.
- На clean є нічия лідерів, тому старий `rank_reversal=False` для всіх сценаріїв був некоректним висновком.
- Некоректна кластер-робастна F-статистика у вихідному звіті: -1.342e10 — не інтерпретувати.
- Повторно виконано та перевірено аналітичні комірки 14/16/18 на прогнозах із архіву; реальний інференс моделей на віддаленому сервері цим локальним тестом не перевірявся.

## Запуск на сервері

1. Відкрийте `SAADE_AUA_v7_1_SCENARIO_EVALUATION_FIXED.ipynb`.
2. Для повної перевірки встановіть `MAX_PAIRS = None` в налаштуваннях (комірка `0. Налаштування`).
3. `EVAL_SPLITS = ('validation',)` залиште без змін — hidden test закрито.
4. Виконайте **Kernel → Restart Kernel and Run All Cells**.
5. Надішліть ZIP `SAADE_SCENARIO_EVALUATION_v7_FULL_FOR_REVIEW.zip` з `/home/jovyan/work/audio_real_fake/results/`.

## Межі наукового висновку

Validation містить лише один ідентифікований синтетичний голос `tetiana`; повний запуск на 94 парах не перетворює його на перевірку інших TTS-голосів або генераторів. Для статті потрібна багатоголосова та міжгенераторна валідація і верифікація вихідних класів детекторів. Шість і більше парних сценаріїв з екстремальним ROC-AUC не треба описувати як доведену вразливість без повторної перевірки.
