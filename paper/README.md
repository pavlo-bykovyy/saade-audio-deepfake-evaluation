# Код підготовки рисунків і рукопису

`tools/build_results.py` — скрипт підготовки кількісних рисунків і документа Results; `tools/translate_ua.py` — українська редакція; `tools/move_figures_to_appendix.py` — розподіл рисунків між текстом і додатками.

Скрипти **потребують окремих** архівів результатів v9.1 та v9.2 і можуть містити шляхи, характерні для середовища підготовки статті. Дані, DOCX і PNG не додаються до source-code архіву.
