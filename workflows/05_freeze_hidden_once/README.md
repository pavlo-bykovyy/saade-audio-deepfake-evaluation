# SAADE–AUA v9.2 — фінальний FREEZE → HIDDEN_ONCE

**Призначення.** Завершити повний науковий протокол v9.1 після виправлення repeat-padding. Це **не навчання** і не новий повний прогін AUA: 876 330 прогнозів уже є. Новий ноутбук використовує їх як зафіксовану основу, а потім одноразово перевіряє 69 раніше відкладених REAL–TTS пар (`lada`, Piper) на трьох готових моделях і 21 сценарії.

**Єдиний файл для JupyterLab:** `SAADE_AUA_v9_2_FINAL_FREEZE_HIDDEN_ONCE.ipynb`.

## Запуск, два послідовні етапи в одному ноутбуці

**1. FREEZE.** Завантажте `.ipynb` у JupyterLab. Залиште у конфігурації:

```python
RUN_PHASE = 'FREEZE'
HIDDEN_CONFIRMATION = 'NO'
```

Запустіть **Kernel → Restart Kernel and Run All Cells**. Програма має повідомити `FREEZE УСПІШНИЙ`. Вона перевірить точні SHA-256 файлів із переданого архіву v9.1, контрольні суми AASIST/AASIST-L, пороги й маніфест, після чого створить `FROZEN_PROTOCOL_v9_1.json`. **Приховані WAV не оцінюються.**

**2. HIDDEN_ONCE.** У цьому **самому** `.ipynb` змініть тільки:

```python
RUN_PHASE = 'HIDDEN_ONCE'
HIDDEN_CONFIRMATION = 'I_AUTHORIZE_ONE_FINAL_HIDDEN_TEST'
```

Знову виконайте **Kernel → Restart Kernel and Run All Cells**. Після перевірки відповідності фіксованому протоколу буде виконано **69 пар × 2 класи × 21 сценарій × 3 моделі = 8694 прогнози**. Ваги й пороги не змінюються. Для AASIST/AASIST-L використовується `repeat-padding` до 64 600 семплів, для Wav2Vec2 — та сама обробка, що у v9.1.

**3. Результат.** Надішліть один архів:

`/home/jovyan/work/audio_real_fake/results/SAADE_AUA_v9_2_FINAL_HIDDEN_ONCE_FOR_REVIEW.zip`

Архів містить прогнози hidden без шляхів до WAV, 21 сценарну таблицю по кожній моделі, ASRI-Audio, довірчі інтервали за парним bootstrap, 3 попарні порівняння з поправкою на множинність, порівняння validation ↔ hidden та заморожений протокол.

## Переривання роботи

Якщо Jupyter або сервер перервалися до повідомлення `HIDDEN_ONCE ЗАВЕРШЕНО`, **не видаляйте** SQLite й файли маркерів. Можна знову виконати ті самі комірки з `RUN_PHASE='HIDDEN_ONCE'`: код відновить **той самий запуск**, не оцінюючи повторно вже повністю оброблені записи. Після запису `HIDDEN_ONCE_FINISHED_v9_1.json` повторне оцінювання заблоковано.

Не редагуйте моделі, пороги, сценарії або CSV після FREEZE. Оригінальний каталог `AUA` та папку `Melnyk_dus` код не змінює. Результати v9 і v9.1 не перезаписуються: v9.2 створює лише окремий каталог `SAADE_AUA_2026_v9_1_AASIST_REPEAT_PADDING/FINAL_HIDDEN_v9_1` і ZIP у `results`.

## Що перевірено до передавання

- Структура й синтаксис усіх комірок: **PASS**.
- Наскрізне виконання `FREEZE → HIDDEN_ONCE` на спеціально створених тестових WAV і фіксованих тестових предикторах: **PASS**; справжні hidden-дані не відкривалися.
- 21 акустичний сценарій, агрегація та експорт ZIP: **PASS** на контрольному наборі.
- Відновлення часткового SQLite (пропущено 357 збережених, пораховано 21 відсутній прогноз): **PASS**.
- Заборона повторного тесту після `FINISHED`: **PASS**.
- Завантаження справжніх pretrained-моделей і виконання hidden test на вашому сервері **не тестувалися локально**; ноутбук перевірить SHA checkpoint на місці.

**Наукове обмеження.** Validation мала лише один голос `tetiana`, hidden має один інший голос `lada`. Обидва належать до Piper, тож навіть повний hidden test перевірить незалежність голосу, але **не доведе переносимість на інші TTS-рушії**. Результати train/adaptation не використовуються для вибору моделі чи нового порога після відкриття hidden.
